# 查询当前战争分、分数明细和战争目标累计分

AI 可以在选定战争的议和查询中，读取本国视角的当前总分、原生中文明细和累计战争目标分。这些信息位于 `peace_context.war_context.war_score`；查询沿用当前战争的 `war_id`，不需要增加一个外交动作。

R74 实验中，法国进攻勃艮第，战争目标是夺取阿图瓦。勃艮第仍控制阿图瓦，因此法国的累计目标分为 −0.40，勃艮第为 +0.40。两侧总分均为 0；中文明细还列出一场战斗和两处各 0.07 分的封锁贡献。数值、中文方向与保存文件的攻守双方及目标控制者已经核对。

## 调用方式

先查询当前双方的战争上下文，再将选定的 `war_id` 交回议和查询。本例只有一场共享战争；存在多场战争时，应先选择实际要查询的战争。

```python
discovery = tools.inspect_diplomatic_action("white_peace", "FRA", "BUR")
assert len(discovery["war_contexts"]) == 1
war_id = discovery["war_contexts"][0]["war_id"]

inspection = tools.inspect_diplomatic_action(
    "white_peace", "FRA", "BUR", "initiate",
    {"peace_context": {
        "war_id": war_id, "direction": "demand", "terms": []
    }},
)
score = inspection["peace_context"]["war_context"]["war_score"]
```

选定战争的其他议和方案也会附带该对象。`war_id` 由当前会话查询产生；重新启动游戏后，应重新发现战争上下文。

## 返回字段与单位

| 字段 | 含义 | 本次法国视角结果 |
| --- | --- | --- |
| `mode` | 查询范围 | `whole_war`，整场战争 |
| `perspective` | 数值视角 | `actor`，发起查询的法国 |
| `total.raw / value` | 原生当前战争总分 | `0 / 0` |
| `total.scale` | 总分原始值到战争分点的比例 | `1` |
| `goal.cumulative.raw / value` | 战争目标已累计的分数 | `-400 / -0.4` |
| `goal.cumulative.scale` | 累计目标分的比例 | `1000` |
| `max_score.value` | 总分上限 | `100` |
| `overview_goal_cap.value` | 概览使用的目标分上限 | `25.0` |
| `tooltip.text` | 完整原生中文组成说明 | 目标控制、战斗、封锁各项 |
| `complete / verified` | 本次捕获与上下文核验结果 | 均为 `true` |

数值单位为战争分点 `war_score_point`，显示值为 `raw / scale`。原生总分已经按整数返回，累计目标分与中文明细保留小数；读取方应分别使用各字段的比例。

本次法国的中文目标说明为：`战争目标：防御方控制阿图瓦：-0.40`。接口保留游戏颜色标记，原始文本见实际报告。反向实验查询取得 +0.40，与勃艮第的防守方身份一致。

`status` 区分 `available`、`partial`、`truncated`、`failed` 和 `unknown`。目标是否存在另由 `goal.available`、`presence_verified` 表示；无法读取的值返回空值及相应完整性状态。
