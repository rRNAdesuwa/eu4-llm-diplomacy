# EU4 1.37.5 restricted v19 bootstrap candidate

This new private candidate connects the versioned v19 Host to the preserved
frame-hook installer. It is separate from the v17/v18 loaded modules and the
public diplomacy API. The exact build is sealed for independent review and has
not been loaded. Its Host R2 passed independent offline review; this does not
approve the bootstrap or prove actual runtime behavior.

An explicit bootstrap requires the exact PID, process creation, game SHA,
session, DLL and manifest. It derives all paths beside its own fixed DLL.
No stage is published by installation. External requests have four fixed
stages, FRA to ENG only; stage 4 contains exactly five named spy families.
Preflight readiness and the same Host's authenticated actual results control
stage order. After an explicit batch claim, each item and its later health run
on separate owner callbacks. No per-action effect scanner is included.

The original hook has the same limitations as the reviewed v18 installer:
it preserves reviewed volatile registers, not a full processor XSTATE contract.
Root equality and the server classifier are not strict single-player or world
epoch proofs. All production/effect verification flags remain false. Command
acceptance belongs to the v19 Core; it does not mean the effect was observed.
Loaded code and held objects remain until process exit; no hot replacement,
retry, unload, direct receiver/drain call or cleanup after transfer is offered.

Native logs retain their source protocols. The new outer log hashes the exact
durably appended raw segment per completed controller invocation, including
the controller result, input handle closure, owner entry and fixed identity.
Durable input claims compare the held request; child claims compare the saved
canonical batch and fixed item order. Claims are permanent and never rearmed.

Source-only draft preparation did not compile or load anything. The later
bounded build produced `build-attempt2/eu4_spy_send_lab_1375_v19.dll`, with 465
codec/scheduler assertions, 35 isolated raw-claim assertions, and six Python
wire test methods passing. Claim tests include the exact bootstrap source but
never call BridgeStart, a hook, an engine function, or a process reader.

All 165 manifest sources were unchanged across the build. Host R2 adds two
private callback repairs; the earlier Host draft, original pins and failed
build-driver attempt are preserved. The first driver failed before creating
its output directory; its child stdout/stderr were not retained. No successful
build or execution is inferred for that attempt.

The sealed artifact still requires independent bootstrap review and a
separately reviewed real-journal provenance wrapper/publisher before use.
This candidate never registers a public diplomacy execution backend.
