# EU4 LLM Diplomacy

这是一个连接 **Europa Universalis IV** 与大语言模型（LLM）的实验性项目。

本项目的长期目标，是让 LLM 接管指定 AI 国家的外交决策，同时继续由 Europa Universalis IV 原生 AI 负责军事、经济以及其他游戏系统。

玩家可以直接与由 LLM 控制的国家进行文字谈判：许诺利益、发出威胁、讨论联盟、谈判和平、欺骗对手、背弃承诺。总之，获得真实、丰富的外交体验！

我们确认了游戏本体对外的外交操作接口非常有限，为了将这些操作暴露给外部 LLM，我们确定了逆向 + DLL注入 + Hook的开发路线。本项目正在探索如何实现这一目标，目前的尝试已让我们对这条路线的可行性很有信心。

## 当前状态

本项目目前处于 **早期实验性开发阶段**。

2026-10-16：[EU4 1.37.5 外交研究进展](docs/research-20261016.md)已整理上传，包含120个TAG动作绑定、直接运行时观察工具和60条宣战/议和证据索引。原统一批次为41派发、77拒绝、2未知；后续历史选定效果信号48项、持久化记录44项，完整逐行动效果、1.37.5宣战/议和执行器和LLM接入仍未完成。逆向已暂停，本次为源码与选定证据快照。详见[工具表v8](docs/runtime-capability-map-1375-v8.json)、[统一验证](docs/unified-diplomacy-validation-1375.md)与[英文进展](docs/research-20261016-en.md)。

以下为 EU4 1.37.4 的历史完成与验证范围：

- 通过自定义 Mod 导出部分游戏状态；
- 拦截原生 AI 的宣战、议和的权限，同时为外部发起的和平行为建立授权通道；
- 可外部执行部分外交操作：LLM操控国家向玩家或其他国家宣战，之后索要金币赔款议和；

目前尚未完成：

- 完整的外交行为逆向工程，包括附庸、联姻、改善关系、保独、间谍网等等等等，并将它们全部暴露出对外接口；
- LLM 信息获取的完善与信息边界设定；
- 对原生AI全部外交权限的剥夺；
- 可正式使用的 LLM 接口；
- 完善的 LLM 扮演国家的提示词，设计外交决策 Agent、上下文管理、长期记忆、谈判和战略规划；
- 技术问题全部解决后，还需要针对可玩性下更多的功夫来调整！
- 最后，还要确保项目稳定且与版本兼容性。

有关当前研究状态、实验记录和技术验证，请参阅 `HANDOFF.md`、`PLAN.md` 和 `VALIDATION.md`。

## 获取和使用方式

1. 克隆或直接复制本仓库地址给您的agent，再一并附上您本地的EU4安装目录（eu4.exe启动器所在文件夹）和数据目录（通常是C:\Users\您的用户名\Documents\Paradox Interactive\Europa Universalis IV）,由 Agent 协助完成环境配置、构建和复现实验。

2. 如果您想自己动手，可以克隆本仓库，按照[路径配置](docs/%E8%B7%AF%E5%BE%84%E9%85%8D%E7%BD%AE.md)完成本地配置，然后按 [复现流程](docs/人工实验与日志读取流程.md) 走一遍。

>

>

## 参与开发

本项目目前仍处于早期研究与开发阶段，也非常欢迎对 EU4 Mod、逆向工程、编程、 LLM Agent 感兴趣的开发者参与。我们不要求参与者熟悉项目全貌，哪怕您的编程水平不高，只要拥有兴趣、一定的空闲时间和AI额度(😂)，想必也能做出贡献。

包括但不限于以下方向：

- **项目协调管理**：如果您有与他人合作开发项目的经验，欢迎您参与到整个项目的协调管理中；
- **EU4 逆向分析**：分析外交相关内部对象、函数、Action 类型、调用链及版本差异；
- **外交接口扩展**：继续实现联盟、王室联姻、保证独立、军事通行权、议和条款等外交行为；
- **LLM Agent**：设计外交决策 Agent、上下文管理、长期记忆、谈判和战略规划；
- **信息边界设计**：研究如何只向 LLM 提供其在游戏规则下合理可知的信息，避免读取完整存档造成“全知 AI”；
- **版本兼容**：研究不同 EU4 版本之间的内部结构变化及兼容方案；
- **测试与复现**：在不同环境中复现实验、验证结果并完善自动化测试；
- **文档**：整理逆向发现、架构说明、复现流程以及开发者文档。


项目目前并不要求贡献者一次完成完整功能。即使只是提交实验结果、提供某个函数的逆向分析、测试不同 EU4 版本，或者参与技术讨论，也非常欢迎。

如果你对某个方向感兴趣，可以直接：

2. 创建 GitHub Issue 讨论想法或实验结果；
3. 在现有 Issue 下参与讨论；
