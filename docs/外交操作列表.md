# 《欧陆风云4》外交操作（Diplomatic Actions）表格

## 注意事项
大部分外交操作都有限制条件，比如对附庸国就无法结盟、建立间谍网等；比如UI界面中保证独立按钮放在其他国籍的附庸国就变成支持独立，而内部代码对应则不明；王室联姻是否可用取决于双方当前政府与改革规则，Signoria 和荷兰共和国存在原生允许例外，不能按“共和国”标签一概排除；还有议和时很多条款是否能使用也有条件。这里面复杂的逻辑依赖关系不能自己重写，而必须复用游戏内判定流程。不过，按钮显示、动作合法性、条款可用性和对方接受意愿可能由不同入口处理；找到发送函数，还不能证明这些限制都已保留。整理时应增加“原生规则复用”这一验收项，以及为LLM提供合法性、接受度查询接口。

### 已验收的单方断盟实例

r24 已实际执行法兰西→普罗旺斯的 `Dissolve Alliance`。该动作由发起国单方执行，不需要对方接受；执行报告的 10 项检查全部通过，执行前后的外交官可用数为 1→0。对应的 [执行报告](../work/runtime/alliance-query-20261015-r24-dissolve-a/dissolve-execution-5db2994d34db45f69b8b6a808378a1ac/report.json)、[来源链报告](../work/runtime/alliance-query-20261015-r24-dissolve-a/dissolve-execution-5db2994d34db45f69b8b6a808378a1ac/native-source-chain-validation-001.json)和[保存重载报告](../work/runtime/alliance-query-20261015-r24-dissolve-reload/reload-validation-798ab399b77f4db0972d4bc535cb0816/report.json)只证明 FRA→PRO 这条路径；其他目标和来源仍需分别查询与验收。
