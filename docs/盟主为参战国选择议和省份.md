# 盟主为参战国选择议和省份

法国作为战争盟主，已经通过统一接口选择并实际发送了“勃艮第把省份88交给奥尔良，并向法国支付1金币”的组合和约。勃艮第原生AI拒绝了这份要求。另两份萨伏依受益的查询，明确返回“萨伏依不想要”和“萨伏依无法将其核心化”；非法执行也返回相同原因。

## 怎样指定其他受益国

行动国、谈判对手与省份受益国分别填写。下面的法国负责提出和约，勃艮第负责回应，奥尔良负责接收省份：

```python
parameters = {
    "peace_context": {
        "war_id": selected_war_id,
        "direction": "demand",
        "terms": [
            {"action_id": "demand_ducats", "amount": "1.0",
             "payer": "BUR", "claimant": "FRA"},
            {"action_id": "cede_province", "province_ids": [88],
             "beneficiary": "ORL"},
        ],
    },
}
inspection = tools.inspect_diplomatic_action(
    "cede_province", "FRA", "BUR", parameters=parameters,
)
```

省份编号和受益国应从当前战争的原生候选中选择。引擎优先把同侧占领国设为受益国；其他情况还会检查同侧核心国等条件。调用方不能通过改写候选标签指定一个游戏没有生成的受益国。

本场景的原生战争和保存字段表明：法国是原始攻击国，奥尔良和萨伏依均在攻击方。实验存档只把三个省份的控制国改为奥尔良或萨伏依，所有者仍是勃艮第。游戏实际载入后，原生候选据此生成了对应受益国。
