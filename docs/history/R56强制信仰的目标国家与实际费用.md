# R56：强制信仰的目标国家与实际费用

本轮已完成强制信仰的原生查询、法国主动要求被伦斯特拒绝、法国对外来提议明确拒绝与接受，以及三种结果的保存和新进程重载。法国接受后，伦斯特及其首都由胡斯派改为天主教，战争结束。葡萄牙 POR 是界面玩家，法国 FRA 是桥接受控国家，伦斯特 LEI 是原生 NPC 对手。查询和入站提议都使用游戏的 `force_religion` 条款；条款中的 `country` 是将改变宗教的目标国家，`beneficiary` 是提供宗教参照的受益国家。提议方向不会替换这两个角色，也不能只根据“谁发起提议”推断条款字段。

已确认的费用是原生战争分数的整数读数：在法国要求伦斯特改宗的场景中，选中条款增量为 `8`、允许上限为 `100`；反向让步候选中，法国作为目标国家时增量为 `270`、上限仍为 `100`。这些事件报告把单位标为 `native_war_score_raw`，但 `unit_scale_verified=false`，因此本文保留原始值，不把它换算成百分比，也不写成 82.5。

## 国家角色和条款语义

| 对象 | R56 中的角色 |
| --- | --- |
| POR | 当前界面玩家和暂停观察者；没有被当作议和提议者。 |
| FRA | 桥接控制的受控国家。在 B 查询中是提议方和受益方；在 C 的入站 offer 中是接收提议并作出决定的国家。 |
| LEI | 原生 NPC 对手。在 B/C 的小国战争场景中是另一方；C 的入站 offer 由操作员指定为 LEI→FRA。 |
| `country` | 强制信仰实际作用的目标国家。该国及其首都宗教会在接受后的效果中读取。 |
| `beneficiary` | 宗教参照和受益国家。强制信仰采用该国当前宗教，实际结果以原生前后读数为准。 |

公共调用把方向和条款一起放在 `peace_context` 中。例如法国要求 LEI 改宗时，条款角色是 `country=LEI`、`beneficiary=FRA`：

```json
{
  "peace_context": {
    "war_id": "<从当前战争查询取得>",
    "direction": "demand",
    "terms": [
      {"action_id": "force_religion", "country": "LEI", "beneficiary": "FRA"}
    ]
  }
}
```

## A：战争上下文的准备边界

A 使用固定脚本把法国与英国从和平状态带入运行中的战争，报告通过了身份、暂停日期、双方国家和战争状态转换检查。该动作的模式是 `operator_prepared_war_context`，没有切换玩家、推进时间、发送议和或保存议和结果。
