# Linked truce selected-path projection candidate

`linked_truce_projection.py` supports `check`, `catalog` and `status --pid N --creation FILETIME16 --actor TAG --target TAG`. This independent candidate does not change the frozen direct-truce v1 or stable observer entry. The current manifest is a draft: file-only check/catalog are available; actual status is rejected before observer construction until independent source review and a production manifest authorize read-only capture. No live capture has been performed for this candidate.

Successful status computes `selected_native_return_projection` as a strict boolean. Both true and false return exit0. Unsupported/incomplete paths return null/exit2 without retry. `actual_native_predicate_evaluated`, action/peace completion, expiry, native readiness, lease and atomicity are always false. This is external state interpreted under selected native normal-path hypotheses, never a call to a game predicate or evidence of a diplomacy request effect.

Only these cases are implemented:

- A: target+0x18f0 is exactly sentinel0x2d2d2d; the normal short circuit leads to the direct actor-to-target cache bit.
- B: target's linked handle resolves to a current full country, bilateral root+0x128 indexes agree on one typed dependency with complete endpoints/removal/key guards, and rawU+0x11a is nonzero with linked==actor. The selected2f false path leads to the direct cache bit.
- C: actor is strictly sentinel-independent, the same target-linked dependency is guarded, U+0x1c8's four raw bytes+0x60..0x63 are zero, and live guardedK is15. The fixedR37/R42/R43 normal-path assumptions give b1e020AL0/2ftrue. Only an observed clear actor-to-linked cache lets this projection continue to the direct actor-to-target cache. A selfpair or set/missing linked cache remains unknown;40a6d0/7ae260 are not followed.

P has the frozen dependency vtable/endpoints/removal guards. A dependency marker357 is not asserted;357 belongs to country/relation roots. U is only the QWORD[P+0x40] pointer used by the frozen key reader and the fixed machine byte profile. Its exact class, size and vtable are unproved. C does not read vector fields unused by the R42 null-actor-getter path.

The default library exact-compiles the pinned direct-v1 source and reuses its Libraries, held identity, host samples, R24 aligned country/pair guards and frozen relation/index/dependency_key functions. Old main/capture,80340 authority, session/publisher, REA and Frida are never invoked. Fresh supplied PID/creation are mandatory. Two passes independently retain full1380 pointer tables, selected complete handles, typed records, dependency/key/field facts and identical projections. Code/K bytes are compared before and after all selected reads: R23 helper229B, complete2f131B, R37 owned128B, R40 owned3421B andK8B. Code identity sampling is not a world or object lease.

An ordered raw read journal covers the shared selected BudgetReader, including code/K checks and both full tables. Its bounded call accounting counts attempted validated reader operations; a failed alignment/short read is not claimed as a successful OS RPM. RuntimeCapture's8192B PE identity read and host pre/post budgets are separate. Output is committed only after normal context exit, held.handle is None and final source guards. OS CloseHandle success is not independently asserted. No pointer is reused after leaving that held capture.

Candidate source/tests use pure synthetic byte fixtures and fake RuntimeCapture. `build_manifest.py` writes a fresh draft manifest once. `run_offline.py` runs only this new test file into an exclusive report directory; it never runs an old suite or game capture. No HTTP, save/load, writes, native calls, hooks or auto-retry are exposed.
