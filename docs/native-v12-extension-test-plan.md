## 建议顺序

1. 完成上述无发送阶段与夹具核验，先对八个正向入口分别做无发送legality并保存原始结果。取消入口只在已有正确对象时安排，不为凑正反数量盲发。拒绝原因保持原始数字；没有已审映射就不猜原因。
2. 先尝试POR贸易权正向→观察→匹配取消→观察，再尝试转移贸易同一闭环。需要等回复或推进日期时，每次只用受监督短租约，重新确认最新暂停/lease结束；一次原生拒绝不自动重发。缺关系或不接受时跳过该组取消。
3. 在新的同日经济快照间测试固定赠款；无法获得同日精确前后差额则记unknown，不推进日期“等余额匹配”。随后测试警告，分别重新采样，避免把赠款前基线用于警告后的其他操作。
4. 包围网、独立支持、人情换金币、侮辱在本夹具默认保留legality结论。前两类虽具观察器，若日后只读证据闭合前提，应新建具体实验而非扩大本轮通过数。
5. 收尾只保存并新进程重载本轮实际存在的持久关系；正向后又取消的条约最终仅能核验取消态，若要证明正向持久性须另有正向存档。经济余额/人情一致可另列选定标量持久性，不能把它当完整账务或请求因果证明。原日志、状态、前后样本和存档SHA各自固定审核后才更新能力索引。

本计划不承诺八族或十二ID全部effect通过；优先目标是最多四族有条件效果（两类贸易包含真实正反闭环），其余保留明确的合法性或观察缺口。冻结/unknown即停止该会话，不能把应用层序号重发当恢复手段。
