Each cleanup rechecks current original fields/type/String32 and command/clone independent ownership/type/fields; command cleanup does this again after original destruction. Identity and clock guards also surround cleanup reads. Unknown ownership/fields freeze; no guessed destructor, reconstruction or retry is introduced.
