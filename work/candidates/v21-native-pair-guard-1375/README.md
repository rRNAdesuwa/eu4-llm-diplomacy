# Native pair guard composition draft

This private C++ component composes the existing reviewed V19 `NativeEnvironment` callbacks with the reviewed C++ TAG resolver and a five-family cancellation reader. A future owner Host must construct the actual Environment through `NativeEnvironment::initialize`, hold a durable claim and call `begin_frame` before a single lease. This candidate has no bootstrap, hook, export, wire consumer, publisher, durable claim, sender or production backend.

`CompiledEnvironmentBinding` implements that concrete initialization composition using the unchanged NativeEnvironment. It is compiled to a separate object and never linked or instantiated in the fake executable. It exposes no entry point. This does not certify an actual Host, module lifecycle or live initialization.

The adapter declaration copy under `port/` changes one include path to the single canonical R2 component header. Its Platform header is copied exactly. Identical declarations in two physical pragma-once headers otherwise conflict in one translation unit. The failed first build and original sources are preserved; `header-composition.json` records the sole include change. No frozen component or adapter source was edited.

The guard locks the original <=60 second expiry, complete actor/target country handles and objects, ordinary current player, roots/count/capacity/date, owner thread, manual pause, reset/load and non-ironman state. It checks the existing multiplayer classifier but does not claim strict single player. Full TAG resolution is done twice for each stamp. It adapts 32 KiB logical reads to the sealed environment's 64-byte reader; that environment enforces its frame-wide 262144-call/16 MiB budget and SEH checks. A source failure permanently freezes this guard. It cannot rearm a lease.

The private adapter Authority callback first reads current world/identity. Its final operation and write callbacks recheck the current selected cancellation graph (for negative work), selected roots/full handles and health, then take a fresh monotonic clock. Cleanup ignores expiry only; it still checks identity and clock rollback. The final callback follows the adapter's loaded-code, ownership and field reads. No public request supplies a pointer, handle, callback, token, envoy, force or permission flag.

`world_witness=1`, session and manifest labels are private observation labels, not a world epoch or cryptographic capabilities. The full bootstrap Identity and held disk files remain in the actual Host environment. Sequential observations do not establish a lifetime lock or exclude ABA. A forged in-process Environment value is not authenticated by this class; the future actual Host must enforce the composition path. Tests deliberately inject fake callbacks and cannot prove OS/game attestation.

StopSpyNetwork is explicitly rejected at the lease boundary because the sealed R2 core expects envoy -1 after the real cancellation setter, which actually writes the selected nonnegative envoy. A new R3 core and typed entry integration are required before enabling this mode. Positive spy actions and five other positive/negative families can be composed for no-send tests. No mode is exposed through the formal execution API by this candidate.

The test executable links the concrete guard, country resolver, cancellation reader and R2 component, using only an in-memory fake Environment. It does not instantiate NativeEnvironment, load a DLL, inspect a process or enter a game function. Compiler/test descendants are contained in a 768 MiB/55 second analysis job.
