## `declaration_details` 字段

公开结果的 `declaration_details.source` 为 `native_declare_war_dialog`。结果同时提供总 `complete` 和分项完整性：CB 的名称与说明、战争目标的 `applicable`、名称与说明、禁用议和条件说明，以及完整宣战描述。无 CB 查询的 `war_goal.applicable=false` 是“当前请求没有战争目标”的明确结果；它不表示所有 CB 或战争目标都已完成结构化映射。ENG/BUR 的 7 个 raw native 事件中，可适用字段均完整。

接口调用示例：

```python
inspection = tools.inspect_diplomatic_action(
    "declare_war", "FRA", "ENG", phase="initiate",
    parameters={
        "casus_belli": "cb_core",
        "war_goal": {"province_id": 167, "beneficiary": "FRA"},
        "call_allies": [],
    },
)
```

调用方使用游戏省份编号和国家标签；CB 名称、战争目标名称、说明、完整性和关系叙述从 `inspection["declaration_details"]` 读取。空 `{}` 只做默认对象和候选发现；显式参数查询才会验证对应 CB、战争目标和原生 details。
