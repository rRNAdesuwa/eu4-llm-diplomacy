# 普通侮辱与轻蔑侮辱接口

更新：2026-10-16。统一接口已实际执行法兰西向勃艮第发送普通侮辱、向热那亚发送轻蔑侮辱，并完成两项后果的保存和新进程重载。玩家国家是 POR（葡萄牙），接口行动国是 FRA（法兰西）；BUR（勃艮第）与 GEN（热那亚）继续由游戏控制。

## AI 如何调用

两个动作都是单方外交选择，使用 `actor="FRA"`、`phase="initiate"`。目标国无需接受或拒绝，接受度返回 `not_applicable`，成功结果返回 `executed`。

| 动作 | `action_id` | 参数 | 原生参数 |
| --- | --- | --- | --- |
| 普通侮辱 | `send_insult` | `{}` | `insult_id=-1` |
| 轻蔑侮辱 | `scornful_insult` | `{"insult_id":0}` 等当前合法候选 | 非负候选编号 |

AI 先列出动作，再查询和选择候选，随后使用唯一请求编号提交，最后读取结果：

```json
{"tool":"list_diplomatic_actions","arguments":{"actor":"FRA","recipient":"GEN","category":"diplomatic_action"}}
{"tool":"inspect_diplomatic_action","arguments":{"action_id":"scornful_insult","actor":"FRA","recipient":"GEN","phase":"initiate","parameters":{}}}
{"tool":"inspect_diplomatic_action","arguments":{"action_id":"scornful_insult","actor":"FRA","recipient":"GEN","phase":"initiate","parameters":{"insult_id":0}}}
{"tool":"execute_diplomatic_action","arguments":{"request_id":"my_scornful_gen_001","action_id":"scornful_insult","actor":"FRA","recipient":"GEN","phase":"initiate","parameters":{"insult_id":0}}}
{"tool":"get_diplomatic_result","arguments":{"request_id":"my_scornful_gen_001"}}
```

轻蔑侮辱的空参数查询用于取得 `parameters.candidates.items` 中的编号和中文文本。选定编号后再次查询，才能取得该选择的完整合法性；空参数发现阶段的 `legality.status="unknown"` 表示尚未选择具体文本。候选由当前游戏条件过滤，执行时还会重新检查。调用方应使用本次查询返回的编号。

普通侮辱直接使用空参数 `{}`。同一请求编号重复调用返回已有结果；提交后遇到读取异常，应通过 `get_diplomatic_result` 回收原结果。

## 查询返回哪些信息

| 字段 | 含义 |
| --- | --- |
| `visibility`、`legality` | 原生外交列表是否显示该动作，以及当前是否允许执行 |
| `native_diagnostic.text` | 游戏返回的禁止原因，例如战争状态、外交官不足、再次侮辱冷却 |
| `insult_active`、`opinion_modifier_raw` | 目标国对行动国是否已有对应侮辱修正，以及修正的原始数值 |
| `actor_prestige_raw`、`prestige_cost_raw` | 行动国当前威望，以及原生配置中的此次威望费用 |
| `parameters.candidates` | 轻蔑侮辱当前合法的候选编号与本地化文本 |
| `resources.diplomats` | 原生外交官需求与当前可用数 |

普通和轻蔑修正分别查询。关系修正已经存在、外交官正在返程，以及允许再次发送侮辱，是三个独立状态。例如本轮热那亚在轻蔑侮辱后仍能查到修正，但游戏明确提示 1455 年 10 月 11 日前不能再次侮辱。

统一 `costs.items` 已返回威望条目：普通 `amount=0`，轻蔑 `amount=5`；同时保留 `amount_raw`、`scale=1000` 和尺度验证标记。该条目的费用及尺度已经确认，其他可能费用的覆盖单独记录在 `costs.coverage`。[最新实际费用查询](../work/runtime/diplomacy-query-20261015-r33-insult-c-reload/insult-queries-b67a9095d3504e439d229b28a245bf0c/report.json)。

## 原生实现依据与本轮修正

两个动作使用同一 Insult 家族：选择器 `0x2947`，对象大小 72 字节，`+0x40` 保存有符号候选编号。工厂默认 −1 表示普通侮辱，非负编号表示轻蔑侮辱。复制与序列化保留该参数；桥接授权把编号与双方、日期、阶段和对象来源一起核对。

查询复用原生显示与合法性函数、候选条件和文本生成函数。执行沿原生构造、复制、传输、重建和处理流程完成关系修正、威望费用与外交官分配。静态函数、ABI 和费用位置见[集成报告](../work/runtime/insult-integration-20261015-001/report.md)与[参数和费用报告](../work/runtime/insult-parameters-20261015-001/report.md)。

第一条普通侮辱已在游戏中成功执行，但 API 结果解码的类方法误用 `self`，原执行报告因此失败。修正后只读回收原请求并通过验收，没有再次提交。操作器也修正了两项判断：普通侮辱只要求自身查询完整；调用计数在进入 API 前记录，异常后的是否提交由原生回执和持久日志判断。
