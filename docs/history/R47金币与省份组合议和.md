## AI如何提交组合条款

统一工具使用 `inspect_diplomatic_action`、`execute_diplomatic_action` 和 `get_diplomatic_result`。以下为本次查询的业务参数；战争编号由当前会话的战争发现查询取得。

```json
{
  "action_id": "cede_province",
  "actor": "FRA",
  "recipient": "ENG",
  "phase": "initiate",
  "parameters": {
    "peace_context": {
      "war_id": "war_d6645b13a62adf39_00000001",
      "direction": "offer",
      "terms": [
        {"action_id": "demand_ducats", "amount": "1.0", "payer": "FRA", "claimant": "ENG"},
        {"action_id": "cede_province", "province_ids": [4388, 4111, 4112, 4389], "beneficiary": "ENG"}
      ]
    }
  }
}
```

本轮增加一次组合查询：DLL在同一个原生和约中设置金额和省份，再构造动作副本，核对金额、省份、方向、参与国及全部序列化条款。合法性和接受度都针对这份组合计算。Python根据专用能力 `native_peace_combined_query` 选择该路径。

本次原生和约含84个候选条款对象，其中5项被选中。四个省份各占一项，金额使用原生默认的金币对象；公开输入的两个业务条款与原生对象数量有明确对应。省份在原生容器中按候选顺序返回4111、4112、4388、4389，接口核对省份集合及受益国。

结果中的 `effects.money` 返回付款方、实付原始值和各国收入，`currency_scale=1000` 表示1000原始单位等于1金币；`effects.provinces` 返回每个省份的所有者、控制者前后值。混合和约只有在付款与全部省份变化都成立时，才确认条款后果。完整实际查询见[组合查询结果](../../work/runtime/diplomacy-query-20261017-r47-peace-a-combined/mixed-query-001/result.json)。
