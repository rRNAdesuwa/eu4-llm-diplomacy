# 议和费用与影响查询

## R66：按国家计算当前与净过度扩张

`peace_consequences.overextension.countries` 已提供当前、取得、失去、净变化和最终OE，数值同时给出原始整数、比例和百分点。A/B两个真实载入场景各完成12份预览，各有26项独立保存字段核对通过；B的非核心省88样本使BUR预计OE从12%下降至0，FRA增加12个百分点。详细字段与调用见[净OE说明](宣战条款与议和净OE预览.md)。释放国家的完整失地清单仍返回不完整状态。

开发目标是让 AI 在提交和约前，读取当前所选条款的外交点费用、侵略扩张、潜在包围网国家，以及取得省份后的造核行政点和新增过度扩张。查询复用游戏原生和约对象与计算函数，费用对应查询中选定的战争、索取或让步方向、条款和受益国。

## 调用方式

先调用 `inspect_diplomatic_action("white_peace", "FRA", "BUR", parameters={})` 取得两国共同战争，再从返回结果中选择 `war_id`。下例展示向勃艮第索取省份、由法国取得省份时的参数结构；`war_id` 和省份编号需要使用当前查询返回的候选值。

```python
parameters = {
    "peace_context": {
        "war_id": selected_war_id,
        "direction": "demand",
        "terms": [{
            "action_id": "cede_province",
            "province_ids": selected_province_ids,
            "beneficiary": "FRA",
        }],
    },
}
result = tools.inspect_diplomatic_action(
    "cede_province", "FRA", "BUR", parameters=parameters,
)
preview = result["peace_consequences"]
```

`direction="offer"` 表示行动国向对方让步。每项费用都携带承担费用的国家或取得省份的国家，调用方应读取这些国家字段。

## 返回字段

| 字段 | AI 可以读取的含义 |
| --- | --- |
| `diplomatic_power` | 无理要求等条款产生的外交点费用、承担费用的国家、数值是否可取得。单位为点。 |
| `aggressive_expansion` | 游戏计算的最大侵略扩张、原生说明文字和包围网风险标记。`maximum_raw / scale` 是关系惩罚数值。 |
| `coalition.countries` | 游戏筛选后可能加入包围网的国家、各国新增侵略扩张，以及该国现有的侵略扩张关系修正。 |
| `territorial` | 按取得省份的国家分组，提供所选割让省份、各省是否已有核心、造核行政点和新增过度扩张。 |
| `complete` | 本份和约的上述预览是否全部取得；各组也保留自己的可取得状态和完整性。 |
| `requested_terms_applied` | 游戏是否实际选中了请求指定的条款。只有为 `true` 时，才能把费用解释为该请求的费用。 |

当候选不存在、受益国不匹配或某项选择未应用时，接口将 `parameters.actual` 设为 `null`，并返回 `requested_terms_applied=false`、`complete=false` 和原因 `NATIVE_PEACE_REQUESTED_TERMS_NOT_APPLIED`。外交点、侵略扩张和包围网预览同时标记为不可用。诊断中保留临时和约的原始数值，AI 应先读取可用状态，避免把尚未应用的方案当成零费用方案。

当前省份预览沿用议和界面返回的割让省份列表。`overextension_added_fraction` 是比例，`overextension_added_percentage_points` 是界面所示的百分点。例如 `raw=120, scale=1000` 对应比例 `0.12`、新增过度扩张 `12%`。后续会补充失去省份后的减少量和净变化。

包围网记录的 `current_aggressive_expansion_modifier` 是已有的侵略扩张关系修正。例如英格兰现有修正为 `-43`，两省方案新增侵略扩张约 `11` 点，原生计算将英格兰列入潜在包围网名单。每国新增量是原生名单使用的整数显示值；最大侵略扩张另保留千分制精度。
