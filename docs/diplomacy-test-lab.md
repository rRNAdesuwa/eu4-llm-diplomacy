## 安装与使用

配置 `local.env` 后在仓库运行：

```powershell
python -B tools/install_diplomacy_test_mod.py --enable --countries FRA ENG POR
```

安装器备份 `dlc_load.json` 与已有同名测试文件到 `work/backup/diplomacy-test-*`，追加独立 Mod，保留其他启用 Mod 和未知配置字段，不改原版脚本。需要重新启动游戏；请在可丢弃的非铁人战役中实验。

进入地图后，优先在决议页点击 `[TEST] Enable 100 extra diplomats (FRA / ENG / POR)`，它通过隐藏事件给三国增加外交官。对应的 Remove 决议可移除。这样无需经过控制台粘贴/删除文本路径。决议固定作用三国，`--countries` 只调整下列控制台批处理文件。

也可手动输入控制台命令：

```text
run llm_test_diplomats_on.txt
```

它给配置国家各增加 100 名外交官。也可只对一个国家执行 `event llm_diplomacy_test.1 FRA`。移除该国修正用 `event llm_diplomacy_test.2 FRA`；批量移除用 `run llm_test_diplomats_off.txt`。

要恢复原版冷却，先在游戏中移除外交官修正，再退出游戏并运行：

```powershell
python -B tools/install_diplomacy_test_mod.py --disable
```

重新启动后验证普通外交冷却恢复为一个月。禁用不删除测试文件，也不覆盖安装后用户对其他 Mod 的选择；仅从启用列表移除本 Mod。外交官修正已进入存档时，单纯禁用 Mod 不能替代存档回滚。
