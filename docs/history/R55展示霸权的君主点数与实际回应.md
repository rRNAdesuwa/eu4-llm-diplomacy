# R55：展示霸权的君主点数与实际回应

本轮已完成 `show_strength` 的三种实际回应及独立重载：法国 FRA 向英国 ENG 提出的 demand 被原生拒绝，操作员指定的 ENG→FRA offer 先被法国 FRA 拒绝、再被法国接受；A/B、D/F 和 E/G 的原生、公共效果与重载结果均已核对。接受后，法国 FRA 作为 `beneficiary` 的三项君主点数从 `[729,440,122]` 增至 `[829,540,222]`，英国 ENG 的三项点数保持 `[451,269,381]`；英国声望下降 20，法国获得羞辱关系，战争结束。拒绝时战争继续，双方点数保持不变。葡萄牙 POR 只是当前界面玩家和观察者；入站回应由桥接控制的法国 FRA 作出。

这次实验围绕 `show_strength`（展示霸权）条款，观察原生议和是否接受条款，以及接受或拒绝时双方的君主点数、声望和战争状态。实验保存了提议方向、原生回应和效果字段，公共接口只返回国家角色与可读数值，不向使用者暴露进程地址、RVA 或私有生命周期记录。

## 实验中的国家角色

存档中的玩家是葡萄牙 POR；POR 负责暂停并观察战争，英国 ENG 与法国 FRA 是议和双方。R55-A 的公共提议是法国 FRA 向英国 ENG 提出 demand：条款中的 `country=ENG` 表示英国承担该条款的后果，`beneficiary=FRA` 表示法国获得结果。这个角色关系来自实际 `peace_context.terms`，不能根据“提议方”或玩家 POR 的身份臆测。C–G 的入站回应由桥接控制的法国 FRA 作出，POR 仍只是当前界面玩家。

R55 同时保留 offer 方向的接口约定：offer 表示提议方主动把条款交给对方，`show_strength` 的 offer 试验会使用 `country=ENG`、`beneficiary=FRA` 的原生上下文。demand 与 offer 都通过同一个公共和平接口传递 `peace_context.direction` 和 `terms`；方向只改变原生条款角色与检查结果，不能省略条款双方。

## 条款前提与公共调用

`show_strength` 的可用性依赖当前战争的原生 CB 与条款检查。R55 的操作员准备基线中，法国 FRA 是进攻方，英国 ENG 是防守方，CB 为 `cb_humiliate_rotw`，战争目标为 `humiliate_rotw`，目标省份为 236；该基线来自先前的原生查询结果，而不是桥接接口替战争宣战。R55-A 在实际执行前完成了战争配对、双方国家、暂停日期、公共上下文和原生合法性检查；报告把 CB/战争背景作为可复核前提保存，不能把“有战争”简化成所有战争都能使用该条款。原生检查通过后才执行一次，接口不会因为候选存在而自动重试或改变世界状态。

公共请求的核心形状如下，`war_id` 来自当前战争查询，`country` 与 `beneficiary` 明确写在条款中：

```json
{
  "peace_context": {
    "direction": "demand",
    "war_id": "<当前战争>",
    "terms": [
      {"action_id": "show_strength", "country": "ENG", "beneficiary": "FRA"}
    ]
  }
}
```

效果字段包含 `powers_before`、`powers_after`、`powers_delta`、`powers_requested`，以及双方原始声望、`prestige_scale=1000`、`values_readable` 和 `verified`。君主点数按原生整数读取，比例为 1；不能把它当作声望的千分比字段。拒绝时仍返回原生实际读数，但 `verified=false`，不能把未发生结算误写成成功。

## R55-A：法国 demand，英国原生回应拒绝

R55-A 使用请求号 `r55a_strength_demand_001`，法国 FRA 提出 demand，英国 ENG 是 `country`，法国 FRA 是 `beneficiary`。执行调用次数为 1，报告通过 17 项检查；执行前原生合法性与战争状态可读，战争仍在进行。

英国的原生回应是拒绝。公共效果仍完整返回：法国受益方的君主点数前后为 `[729, 440, 122]`，增量为 `[0, 0, 0]`，请求值为 100；英国自己的君主点数为 `[451, 269, 381]`，保持不变。英国声望为 `62778 → 62778`，法国声望为 `-10990 → -10990`，双方声望增量均为 0。`humiliated_before=false`、`humiliated_after=false`，`values_readable=true`，但 `verified=false`，因为原生没有接受并结算该条款。战争保持进行中。
