## R57B：核心条款批量查询已经可用

公开查询沿用完整 `peace_context`，`war_id` 由当前会话的战争查询取得。例如，法国（FRA）要求英国（ENG）把省份 173 归还给持有该省核心的阿马尼亚克（AMG）时，输入可以写成：

```json
{
  "action_id": "return_core",
  "actor": "FRA",
  "recipient": "ENG",
  "phase": "initiate",
  "parameters": {
    "peace_context": {
      "war_id": "war_e77eec97da7bdd15_00000001",
      "direction": "demand",
      "terms": [
        {
          "action_id": "return_core",
          "province_ids": [173],
          "core_owner": "AMG"
        }
      ]
    }
  }
}
```

查询会把候选发现和指定条款分开返回。空 `terms` 的候选发现保持 `unknown`；错误核心国家、不存在省份和只匹配部分省份的输入返回 `unavailable`，且 selected 为 0。这样既能列出原生候选，也不会把未选择条款的接受评价猜成白和平预测。
